<objective>
Create the Phase 1 walking skeleton for Office: one local command starts a localhost-only Fastify API and Vite React web app, the browser shows a nonblank PixiJS office shell without login, a real office setting is persisted through SQLite/Drizzle, and `/health` plus `/ws` establish backend readiness and future live updates.
</objective>

<constraints>
- Do not add auth, Docker, Caddy, public URL handling, vault, Telegram, or real Claude launching in this phase.
- Do not bind the backend to `0.0.0.0`; default host must be `127.0.0.1`.
- Do not create a throwaway HTML/CSS office mock; use PixiJS in the real app.
- Inspect `https://github.com/paulrobello/claude-office` if network is available before implementing visual patterns. Reuse only license-compatible ideas/assets.
- Prefer npm workspaces unless a concrete local blocker appears.
</constraints>
